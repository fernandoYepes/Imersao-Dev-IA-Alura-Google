Uma aplicação interativa de calculadora via linha de comando (CLI), desenvolvida em Python para praticar conceitos fundamentais de lógica de programação, estruturas condicionais e loops.

---

## 📌 Sobre o Projeto

Este projeto foi construído para servir como base de estudos em Python. O programa é executado diretamente no terminal e permite realizar repetidas contas sem a necessidade de reiniciar o script a cada operação, encerrando apenas quando o usuário desejar.

---

## ✨ Funcionalidades

- [x] **Adição (`+`)**: Soma entre dois valores numéricos.
- [x] **Subtração (`-`)**: Diferença entre dois valores.
- [x] **Multiplicação (`*`)**: Produto de dois fatores.
- [x] **Divisão (`/`)**: Quociente entre números com **tratamento para divisão por zero**.
- [x] **Menu Interativo**: Permite realizar múltiplas operações em sequência.
- [x] **Validação de Entrada**: Identifica opções inválidas no menu sem quebrar a execução do programa.

---

## 🧠 Conceitos Praticados

- **Funções (`def`)**: Organização e modularização do código em blocos lógicos.
- **Entrada e Saída (`input()` e `print()`)**: Comunicação direta com o usuário via terminal.
- **Conversão de Tipos (*Type Casting*)**: Conversão de texto para ponto flutuante (`float()`).
- **Controle de Fluxo (`if`, `elif`, `else`)**: Tomada de decisões com base na escolha do usuário.
- **Laços de Repetição (`while True` e `break`)**: Criação de um menu contínuo com opção de saída.
- **Formatação de Texto (*f-strings*)**: Exibição limpa e dinâmica dos cálculos na tela.

## 💻 Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter o [Python 3](https://www.python.org/) instalado em seu computador.

### Passo a passo

1. **Clone o repositório** (ou baixe os arquivos):
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```

2. **Acesse a pasta do projeto**:
   ```bash
   cd NOME-DO-REPOSITORIO
   ```

3. **Abra no VS Code** (opcional):
   ```bash
   code .
   ```

4. **Execute o script no terminal**:
   ```bash
   python calculadora.py
   ```
   *(No Linux/macOS, use `python3 calculadora.py`)*
