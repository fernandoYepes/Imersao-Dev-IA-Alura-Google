# 🚀 Desafio 3: Criando uma Lista de Tarefas com o Google Antigravity

Bem-vindo ao **Desafio 3**! Após compreender, modificar e testar códigos existentes, é hora de construir uma nova aplicação do zero utilizando o assistente de desenvolvimento **Google Antigravity**.

O objetivo principal é criar uma aplicação web simples de **Lista de Tarefas (To-Do List)** com interface visual intuitiva para gerenciamento de atividades no dia a dia.

---

## 🎯 Objetivos do Desafio

Desenvolver uma interface visual amigável que atenda a **três funcionalidades essenciais**:

1. ➕ **Adicionar Tarefas:** Permitir a digitação e inclusão de uma nova atividade na lista.
2. ✅ **Marcar como Concluídas:** Alterar o estado de atividades realizadas para diferenciá-las das pendentes.
3. 🗑️ **Remover Tarefas:** Excluir da lista atividades que não são mais necessárias.

---

## 💡 Guia de Implementação com o Google Antigravity

Siga estes passos recomendados para interagir com o Google Antigravity durante a construção da aplicação:

### Passo 1: Prompt Inicial (Criação)
Envie o comando inicial para estruturar o projeto com tecnologias simples e acessíveis:

> *"Quero criar uma aplicação simples de lista de tarefas, com uma interface visual que permita adicionar, concluir e remover atividades. Estou começando a aprender desenvolvimento de software, então utilize tecnologias simples e organize o projeto de maneira que eu consiga compreender seus principais componentes."*

### Passo 2: Solicitar Melhoria Visual
Após testar a versão inicial, solicite um ajuste de estilo para destacar o estado das tarefas:

> *"Quero que as tarefas concluídas apareçam visualmente diferentes das pendentes. Implemente essa melhoria e explique quais partes do código precisaram ser modificadas."*

### Passo 3: Testes e Validação
Peça ao assistente para validar a estabilidade das funcionalidades:

> *"Execute os testes necessários e verifique se todas as funcionalidades (adicionar, concluir e remover) continuam funcionando perfeitamente."*

---

## 🧠 Aprendizados Esperados

Ao concluir este desafio, você terá desenvolvido competências chave de desenvolvimento de software:

- **Organização de Código:** Compreender como a interface (HTML/CSS) se conecta com a lógica de programação (JavaScript).
- **Gerenciamento de Estado:** Observar como o código lida com a inclusão, alteração e remoção de dados dinâmicos.
- **Engenharia de Prompt para Devs:** Aprender a orientar e iterar com assistentes de IA para construir e aprimorar soluções computacionais.
- **Validação de Testes:** Entender a importância de testar e verificar os resultados antes do envio final.

---

## 📋 Checklist de Entrega

- [ ] Aplicação executa sem erros de console/código.
- [ ] Permite adicionar novas tarefas via campo de texto.
- [ ] Permite marcar/desmarcar tarefas como concluídas.
- [ ] Tarefas concluídas possuem diferenciação visual clara (ex: risco no texto, alteração de cor).
- [ ] Permite excluir tarefas da lista.
- [ ] Código devidamente comentado e explicado pelo Google Antigravity.
